## Complexity

As I progress, I'll practice analyzing algorithms using Big O notation, including:

* `O(1)` — constant
* `O(log n)` — logarithmic
* `O(n)` — linear
* `O(n log n)` — linearithmic
* `O(n²)` — quadratic

## Approach

I'm focusing on understanding **why** an algorithm or data structure works rather than simply memorizing solutions.

For each topic, the goal is to:

1. Understand the concept.
2. Implement it from scratch.
3. Analyze its time and space complexity.
4. Solve problems using it.
5. Experiment with different approaches.
6. Review and improve the implementation.
